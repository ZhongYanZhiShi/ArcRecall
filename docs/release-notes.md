# Release 信息规范

发布说明使用简体中文，面向普通用户，按以下顺序组织。不设置「已知限制」「使用与反馈」或「相关链接」章节。

## 内容结构

| 项目 | 规范 |
| --- | --- |
| 标题 | 固定为 `ArcRecall vX.Y.Z`，与 Git 标签一致。 |
| 版本信息 | 标明发布日期、正式版或预发布版、支持平台。 |
| 版本概述 | 用 1–2 句话说明本次发布的主要价值。 |
| 更新内容 | 按「新增」「优化」「修复」分类，没有内容的分类省略。首次发布可使用「核心功能」。 |
| 安装与升级 | 说明安装包选择、升级方式、数据是否保留，以及必要的兼容性说明和迁移操作。 |

## 写作约定

- 首次发布介绍核心能力，后续版本仅介绍相对上一版的变化。
- 每条更新写清具体变化及其对用户的影响，避免直接堆砌提交信息。
- 保留必要的技术名词，省略与用户操作无关的实现细节。
- 升级必须了解的不兼容变更、数据迁移和手动操作，写入「安装与升级」并突出显示。
- 日期、安装包名称、下载链接和测试结论以实际发布产物及验证结果为准。
- 区分用户需要下载的安装包与 `.sig`、`latest.json` 等更新配套文件。
- 发布前删除占位内容，核实说明与目标版本一致。

## 首次发布示例

以下以 v0.1.0 为例，不代表版本已经发布。实际发布时填写发布日期并核实目标版本功能与产物。

---

# ArcRecall v0.1.0

首次正式发布 · Windows x64

发布日期：待填写

ArcRecall 根据文件内容识别压缩包的真实格式、修正异常后缀，并逐层处理嵌套归档。归档处理和密码验证在本机进行。

### ✨ 核心功能

- **归档识别与后缀修复**：识别受支持的 7z、ZIP 和 RAR 归档，并可生成后缀正确的独立副本，不修改原文件。
- **嵌套归档处理**：逐层分析和解包；遇到加密归档时，在本机验证密码。
- **批量处理**：支持多选、拖入多个归档或粘贴多行路径，按顺序处理，并展示本次会话中每项任务的结果。
- **创建压缩包**：可创建 7z 或 ZIP 归档、设置密码，并可选用已配置的 AI 模型优化新归档的名称。
- **恢复历史**：按归档内容匹配历史记录，同一归档改名后仍可复用已验证的密码。
- **数据备份与恢复**：支持备份和恢复字典、恢复历史，并在恢复前检查备份。
- **日志与诊断**：支持筛选和导出运行日志，帮助排查处理失败的原因。
- **应用内更新**：启动时或在「设置 → 应用」检查后续正式版；下载并校验签名后，由用户确认安装并重启。

### 📦 安装与升级

**首次安装**

在本页 **Assets** 中下载 Windows x64 的 `.exe` 安装包并运行。`.sig` 和 `latest.json` 是应用更新所需的配套文件，无需手动下载。

**后续升级**

本版支持在「设置 → 应用」检查、下载和安装后续正式版。自动下载更新默认开启，可按需关闭；安装更新始终需要用户确认。升级会保留本机设置、字典和恢复历史。

**备份说明**

数据库备份不包含应用设置、AI 密钥和压缩默认密码。含恢复历史密码的备份需在创建备份的同一 Windows 账户下恢复。
